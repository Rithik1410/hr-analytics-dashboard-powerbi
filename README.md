# HR Analytics Dashboard | Power BI

## 📊 Project Overview

An interactive HR Analytics dashboard developed using Power BI to analyze employee attrition, workforce demographics, job roles, salary trends, and employee-related factors.

## 🎯 Objectives

- Analyze overall employee attrition
- Identify factors contributing to employee turnover
- Analyze attrition across departments and job roles
- Understand employee demographics
- Identify salary and experience-related trends
- Provide actionable HR insights through interactive visualizations

## 🛠️ Tools & Technologies

- Power BI
- DAX
- Power Query
- Excel
- Data Visualization

## 📈 Key Insights

- Analyzed employee data across **1,470 employees**
- Overall attrition rate: **16.2%**
- Identified attrition patterns across departments and job roles
- Analyzed employee demographics and compensation trends
- Identified key factors associated with employee attrition
